## استفاده

```php
use Tavaan\Engine\Validation\Validator;

// مستقیم
$validator = Validator::make(
    data: ['email' => 'a@b.c', 'age' => 20, 'mobile' => '09121234567'],
    rules: [
        'email'  => ['required', 'email', 'max:255'],
        'age'    => ['required', 'integer', 'between:18,120'],
        'mobile' => ['required', 'iran_mobile'],
    ],
    messages: ['email.required' => 'ایمیل الزامی است.'],
    attributes: ['email' => 'ایمیل', 'age' => 'سن'],
);

if ($validator->fails()) {
    $errors = $validator->errors();  // ['email' => ['msg'], ...]
    $all = $validator->allErrors();   // flat list
}

$data = $validator->validate();  // throws ValidationException on failure
```

- **حضور**: `required`, `nullable`

- **مقادیر**: `in:v1,v2,...`
- **فرمت**: `email`, `regex:/pattern/`
